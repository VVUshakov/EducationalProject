=====================================
КАК ДОБАВИТЬ НОВУЮ ПРОГРАММУ
=====================================

1. СОЗДАЙТЕ НОВЫЙ КЛАСС:
   - В папке Services создайте новый файл (например, MyProgram.cs)
   - Унаследуйте класс от BaseService
   - Реализуйте свойства Name и метод Run()

2. ДОБАВЬТЕ ПРОГРАММУ В КОНФИГУРАЦИЮ:
   - Откройте файл ProgramsConfig.cs
   - Найдите раздел "НОВЫЕ ПРОГРАММЫ"
   - Раскомментируйте строку: // new MyProgram(),
   - Удалите "// " в начале строки

3. ЗАПУСТИТЕ ПРОЕКТ:
   - Новая программа появится в меню!

=====================================
ПРИМЕР НОВОЙ ПРОГРАММЫ:

namespace EducationalProject.Services
{
    public class MyProgram : BaseService
    {
        public override string Name => "Моя программа";
        
        public override void Run()
        {
            Console.WriteLine("Это моя первая программа!");
        }
    }
}
